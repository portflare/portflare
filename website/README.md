# Portflare website

A static marketing site for Portflare.

## Local preview

Open `index.html` directly in a browser, or serve the directory with any static server:

```bash
python3 -m http.server 8080 -d website
```

Then visit:

```text
http://127.0.0.1:8080
```

## Deployment

The site is dependency-free HTML/CSS/JS and can be deployed to any static host, including GitHub Pages, Cloudflare Pages, Netlify, Caddy, or nginx.
